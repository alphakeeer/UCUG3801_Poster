# E016-A001 规划图集无损分卷

原始PDF为天河区国土空间总体规划（2021—2035年）公开图集，共117,947,103字节。为适配Git远端单文件限制，按48MiB切为3卷，原始字节顺序与完整文件校验值保存在[manifest.json](manifest.json)。本地完整原件保留，Git远端保存这组分卷。

## 还原原件

在仓库根目录运行以下命令，使用Python标准库。

```sh
python3 '03_背景/教育专题/原始文件/E016-A001_分卷/restore.py'
```

程序验证各分卷与完整PDF的SHA-256后，将原件还原到教育专题的原始文件目录。已存在且校验一致时可重复执行，目标存在且校验不符时会停止并保留已有文件。复原后的PDF文件名与下载清单一致，既有索引和分析脚本可直接读取。
