# 猎德教育研究资料包

收集及核对日为2026-11-10。当前研究问题为猎德及周边幼儿园、小学、初中的空间分布，如何与招生资格、学位分配、费用及家庭住房条件相互作用，形成教育机会和负担的差异。

## 本轮保存的内容

- **77项来源载体，约204.4MB，PDF共990页**。包括75项本轮下载和2项已有原件复用，每项登记URL、大小、哈希和下载时间。
- **广州行政区划图、天河空间规划图集，以及猎德、冼村、员村、天河南4幅官方街道地图公开预览**。地图资料日期与下载日期分别记录。
- **2026天河233条幼儿园园区完整记录**，包含教育部门办78、其他部门办35、民办120。
- **猎德及周边30条幼儿园候选、20条小学初中校区学段候选**。幼儿园中10条已有官方猎德街道归属，小学初中20条对应14个机构。周边1公里和2公里筛选仍待坐标核验。
- **14张CSV**，涵盖官方原行、园校、计划、对口、积分指标、年检、收费、家庭申请类别及缺口。
- **2026义务教育细则66页完整扫描附件与OCR检索文本**，关键表格已结合原页查看。
- **21项收费政策、批复与历史价格条目**。新昌小学8700、初中10600元/学期，新蕾小学8000元/学期均取得执行期覆盖2026的正式批复，实际下浮、补贴扣除及附加费另核。

来源载体与独立研究来源分别计数。同一政策的通知和附件按一条文件链理解，预算及历史资料主要用于背景和交叉核验。

## 可以据此继续分析的发现

1. 利民社区华文幼儿园2025开园，2026名录确认国企办及现址，能研究公共配套供给的时间差和政策回应。
2. 猎德幼儿园社会电脑派位135人，其中业主子女85、剩余随机50，能研究住房和户籍怎样进入学位分配。
3. 猎德实验初中与南国初中分别有50和40个来穗积分计划，能研究资格排序、学段差异及公共支持。
4. 免费学前、课后服务减免和民办积分补贴改变不同家庭的潜在支出，需与逐校原价、项目和资格结合。
5. 小学对口与初中派位形成阶段之间的制度联系，地图位置和小学经历共同影响申请范围。

每项事实的原文定位与解释范围见[证据分析](分析证据与局限.md)。
