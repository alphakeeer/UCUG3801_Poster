# 交互地图地理资料与点位说明

获取及核验日期为2026-11-12。这批地理资料为2026-11-10教育研究资料包的展示补充，原77项来源载体和14张研究CSV的统计保持其采集批次口径。

## 地理资料

| 本地文件 | 内容与获取方式 |
| --- | --- |
| `OSM_猎德周边_20261112.json` | Overpass响应原字节，路网、水域、公园、学校及街道边界 |
| `OSM_猎德周边_查询.txt` | 实际Overpass QL查询，保留查询对象、条件与范围 |
| `学校地理编码检索.json` | 46组唯一校址查询的Nominatim响应、查询URL、对应研究记录与日期 |
| `学校点位_WGS84.csv` | 全50条记录的定位状态、WGS84坐标、方法、地图原名、来源URL及局限 |

数据从OpenStreetMap公开Overpass API和Nominatim接口获取。Nominatim按单线程、请求间隔至少1.1秒执行，查询范围为广州，获取响应仅作候选匹配。底图矩形南界23.100、北界23.145、西界113.305、东界113.385，覆盖猎德及相邻候选设施。OSM基准时间另保存在原始响应`osm3s.timestamp_osm_base`字段。

主要入口包括[OSM地图](https://www.openstreetmap.org)、[Overpass API](https://overpass-api.de/api/interpreter)和[Nominatim](https://nominatim.openstreetmap.org)。

## 匹配与位置精度

学校身份以教育部门原名、校区和官方地址为依据，再核对OSM设施名称与校区。27条研究记录取得校园参照位置，包含8条幼儿园、12条小学和7条初中。三个同址小学初中组合合并为地图入口，合计24个入口。23条未取得可靠匹配的记录继续保留官方地址和资料卡。

点要素采用OSM设施坐标，校园面采用小范围经纬度平面的面积几何中心。两类均用于设施参照，实际校门、围墙出入口和行人可达路线需现场核验。地图显示小数精度代表计算与存储格式，实地精度由原始标注及核验情况决定。

海明学校采用OSM“体育东路小学（东校区）”要素，别名与校区对应继续核验。体育西幼儿园、体育东路幼儿园两条地理编码结果均返回“天河区儿童福利会幼儿园”，名称关联证据不足，已排除该匹配。匹配规则在生成脚本保留，原始响应可供追溯。

南国学校小学部与初中部在OSM为不同校园面，按各学段保留位置。猎德实验、华颖及新昌各自同址小学初中，在地图合并入口，详情与列表保留学段。

## 范围与比较口径

猎德街道OSM边界仅作为可交互参考，学校是否列入官方猎德街道名录由教育研究原表记录。社区界、街道界和国际街区界分列。精确社区边界及官方边界矢量化仍需补证。

交互页面默认用绿色半透明覆盖、双层边界线和地名标注显示猎德街道，并提供完整范围定位和四至说明。27条已定位校区学段资料按校园参照点落入参考多边形判断，10条在界内、17条在周边。该判断使用射线法，面内规则与地图边界同源。原始校园位置精度、边界版本以及校区别名影响临界位置解释，学校行政归属继续按官方名录核验。

固定矩形用于控制底图体积。候选学校名单取自先前官方资料收集，边界内的完整设施总量仍需核查，设施密度和覆盖率计算需补人口、完整名录及统一范围。

升学连线表达当年文件支持的申请关系。天河中学按学校层级表示，分校区归属未取得时使用学校层级汇合标记和文字说明。空间线条用于阅读关系，实际通学道路需要另行审计。

## 展示与许可

网站把底图裁剪为约726KB的本地JSON，路网、水域、公园和边界经过同一局部Web Mercator投影。学校位置同样从WGS84转换。此数据按地图交互需要加载一次，运行时地图服务和瓦片请求为零。
