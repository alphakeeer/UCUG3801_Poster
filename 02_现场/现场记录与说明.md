## 2. 去了哪里：猎德（Liede）

- 广州**天河区猎德街道**，约 **3.5 km²**，珠江新城 CBD 一带；今天的「国际街区」有 19 栋 100 米以上高楼、30 家领事馆、2000+ 外籍人士（[官方介绍](https://www.eguangzhou.gov.cn/gzspecialreports/intlblocks/details/liede/content/post_31834.html)）。
- Poster PDF 标题页放的正是 **改造前地图 vs 现在夜景** —— 猎德的前身是**城中村**，是广州「三旧改造」最著名的样本之一。
- 理论背景（Lect 5 阅读 **Ren 2020**，本目录 `03_背景/` 有 PDF）：广州城中村改造以「拆除重建 + 土地财政」为主；房东获补偿/安置房，**租户没有补偿、会被驱逐**；改造后部分村民变富。**这就是现场要观察和验证的机制。**

## 3. 为什么去（3 层理由）

1. **考核**：syllabus 明确 Learning Portfolio 20% 包含「field trip 后的小组 poster」；Course Participation 20% 包含 field trip 参与、数据收集、与居民互动。
2. **方法**：训练 sociological imagination —— 系统观察 → 收集证据 → 用理论解释，而不是写游记（PDF 原话：“The purpose is not simply to describe what you saw.”）。
3. **主题**：一次看齐城市更新、住房、迁移与户口、性别与年龄、职业与服务业经济、阶层与不平等、食物/服务/公共空间可及性、社会流动机会。

## 4. 现场要观察什么（7 组问题）

- [ ] **性别分布**：街上男女比例？可能说明什么？
- [ ] **识别外来人口**：从衣着、语言、行为能否看出？依据是什么？（不得凭外貌下结论，只能用 "may suggest"）
- [ ] **年龄结构**：儿童/青少年/青年/中年/老年哪类最多？
- [ ] **职业与社会阶层**：学生/受雇者（服务业、白领）/自雇（店主、摊贩）？大致阶层？
- [ ] **住房条件**：类型/密度/维护，与广州其他地方比较如何？
- [ ] **食品价格**：小店/餐厅/街边摊比其他区域便宜、相近还是更贵？
- [ ] **社区活跃度**：热闹还是安静？说明什么日常生活状态？

> 现场如有 field trip lecture / 讲解，直接提问：历史、改造中的困难、居民体验。

**原则**：先写“看到什么”，再写“可能意味着什么”，最后写“证据有多强/局限”。

## 6. 补充方法 + 伦理提醒

- 至少 **3 类证据**：系统观察 / 价格或环境审计 / 背景研究（+ 可选访谈）。
- 价格审计要写清：比了什么、为什么选这些、为什么这个比较有意义。
- 不要凭一个人、一次偶遇下结论；同一类地点在不同时间/不同区域重复观察。
- 可选访谈：自我介绍 → 说明目的 → 征得同意 → 不问敏感 → 不施压 → 匿名 → 不留联系方式。
- 照片：只拍建筑、招牌、街道、公共设施；**不拍可识别人脸、不拍儿童**；不进私人楼宇/住宅区。
