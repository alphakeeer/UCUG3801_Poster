研究问题

猎德街公共文化设施的开放时段，如何影响工作与照护日程不同的居民，把“家门口的设施”转化为实际可用的机会？

01社区背景

猎德被称为“广州城中村改造第一村”：2007 年拆迁，2010 年村民回迁 [7]。空间已然跃升，但居住改善与社会融入并不同步 [1,6]。

02概念 · 时空制约

时间地理学认为，人只有在特定时间抵达特定地点，才能获得机会；固定工时与照护责任会压缩个人的“可达”范围 [3]。

03概念 · 实质可及性

可及性由土地利用、交通、时间与个人四要素共同决定 [4]。设施“存在”只是供给，与个人日程交叠后才成为机会。

06社会学分析 · 从“有设施”到“能使用”

  1. 供给8 处 · 2,632 ㎡

    目录登记的设施与面积

  2. 时间门工作日晚间 0 h

    固定工时、轮班与照护者先被筛出

  3. 空间门长时段仅 1 处

    面积为 7 处社区中心之和的 1.6 倍

  4. 使用参与 → 社会资本

    预约、信息与容量仍待核验

社会分层　时间是分配不均的资源：工作日白天能到场的多是退休者与全职照护者；固定工时的雇员与外来务工者更依赖晚间与周末。

机会的转写　统一的白天时段，可能把劳动市场位置的差异转写为文化参与的差异，再经由活动中结识的人与信息，影响社会资本的积累 [3,4]。

07结论

猎德街不缺设施，
缺的是与上班族时间的交叠。

开放时段本身就可能是一道筛选机制，把谁在工作、何时工作的差异，延伸为谁能参与社区文化生活的差异。

下一步晚间是否有未登记的活动？谁在使用，谁从未走进去？

08局限与反身性

  1. 只有登记时段。若晚间有临时活动，错位会被高估。
  2. 空闲时段为假设。只说明潜在不匹配，不能断言某一群体被排斥。
  3. 实地仅一天，未入室内。两社区的入口与活动差异尚无法比较。

我们在周六到访，社区中心只开上午三小时；我们看到的“社区生活”，本身也经过了时段的筛选。
