# 猎德及周边住房价格空间分布调查

用于 UCUG3801《Social Inequality and Social Mobility》猎德教育机会研究的住房背景调查。原始价格记录查询基准为 **2026-11-11**，区域补充分析及补充政策核验日期为 **2026-11-12**。本目录为桌面预调查成果，尚不包含实际开展的系统现场观察或家庭访谈。

## 建议阅读顺序

1. [区域房价分析补充报告](猎德区域房价分析补充报告_2026-11-12.md)：先看核心复建区、站区中西组和东侧扩展组的比较，以及同月与挂牌口径敏感性分析。
2. [完整调查报告](猎德住房空间分布调查报告_2026-11-11.md)：研究范围、17小区记录、住房制度、成交与租赁例证、教育政策接口、社会学解释及现场核验路线。
3. [原始工作簿](猎德住房价格数据_2026-11-11.xlsx)：小区记录、成交记录、租赁证据及来源说明。工作簿保持11月11日冻结版本；后续区域分组及人才公寓补充见下列文件。

## 结论的使用边界

混合月份平台参考记录显示东侧高价样本较集中、站区中西组内部价格混合；仅9月记录或改用单条挂牌例证后，两组中位数接近。因此不能把混合样本约23%的差值写成稳定的区域溢价。分组按道路街区组织，不是行政边界或完整GIS划界。

猎德花园异常出售报价所涉权利未经核实，不纳入普通商品房价格排序；天銮商住产品单列。平台参考值、广告挂牌价和平台标示成交分别记录，不等同政府登记成交价。每小区一个参考记录不代表底层房源数已知，部分价格仅搜索可读，原始页面未完整归档，后续网页可能变化。

新增官方证据确认2026年誉城苑有10套人才公寓纳入配租，标准50元/㎡/月、不含物业费；只适用指定房源及合资格申请人，不代表全小区市场租金。[天河区住建园林局公告，2026-08-13](https://www.thnet.gov.cn/thqzdlyxxgkzl/zfbz/bzxzffphtcxx/content/post_10965824.html)

住房金额和学校距离不能直接证明招生资格、学校录取结果或居民阶层。教育接口及待核问题见报告，现场调查应继续补充同周可比房源、住房权利、合法居住材料和实际通行证据。
