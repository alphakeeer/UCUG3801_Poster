# 猎德教育机会交互地图

《住得近，就能读得上吗？》的中文交互研究展示。以猎德及周边地图为主视图，连接教育设施、住房、户籍、名额分配与费用支持。实现日期为2026-11-12，招生和政策研究资料版本截至2026-11-10，OSM地理资料获取于2026-11-12。

[在线交互地图](https://liede-education-atlas-2026.growingkiwi1.chatgpt.site)采用Sites默认私有访问范围。

## 本地运行

使用Node.js 18或更新版本，在本目录执行。

```sh
npm start
```

浏览器打开 <http://127.0.0.1:4173>。运行和预览使用Node内置模块，安装步骤为零。可用`PORT=4180 npm start`更换端口。

```sh
npm run check
```

该命令检查应用、地图引擎和预览服务器的JavaScript语法。`dist/`可直接交给静态网站服务器托管，页面使用相对资源路径。

## 五种探索模式

| 模式 | 主要交互 | 研究用途 |
| --- | --- | --- |
| 分布 | 拖动、滚轮或双指缩放，按学段、举办主体、名称和地址筛选，切换街道边界 | 观察设施位置与供给类型，查看资料覆盖缺口 |
| 入学 | 选择儿童户籍、居住方式和积分核定情景，学校详情与路径标记联动 | 解释制度性分层，查看住房条件怎样进入名额分配 |
| 费用 | 切换学费或保教费、民办积分补贴、学校提供课后服务，切换适龄大班 | 对照正式批复、减免和补贴的适用条件 |
| 升学 | 点击小学或初中，查看有文件依据的对口连线和来源 | 讨论小学经历与后续教育路径的制度联系 |
| 比较 | 选择两所同学段学校，切换社区比较和公共供给时间线 | 同口径比较入口、计划、费用依据及待核内容 |

学校详情包含概况、入学、费用和证据四个栏目。原始文件标题、日期、学校原行或计划定位与官方链接可从对象进入。来源弹窗打开外部原文，原件归档位于仓库教育专题。

### 猎德地域的识别

绿色半透明覆盖、双层虚线边界和“猎德街道 · 研究主体”地名标注默认显示。范围说明卡的“查看范围”会收起学校详情，并把完整街道轮廓放入地图可见区域。窄屏总览允许在已采集底图外围保留背景留白，以完整呈现范围。

“范围定义与依据”可展开四至参照、猎德街道、猎德社区与猎德国际街区的口径说明，以及官方地图、地域资料和OSM边界来源。已定位27条校区学段资料中，按校园参照点与OSM参考界判断，10条在界内、17条在周边。另23条范围待核。学校档案显示相应空间标记，行政归属仍结合官方原表核验，招生地段按当年文件另核。

右上角“展示导览”提供五个可重置的课堂场景，依次呈现分布、住房与名额、来穗家庭、升学关系以及猎德与利民的公共供给。场景预设用于演示规则。观众可随时继续筛选或选择学校。

手机及窄屏平板使用收起的筛选栏与底部学校抽屉。地图、学校按钮、来源窗口支持键盘操作。按`/`搜索，地图获得焦点后可用方向键移动、`+`和`-`缩放，学校详情标签可用左右方向键、Home和End切换，Esc关闭窗口或详情。

## 数据与解释边界

- 共50条园区或校区学段记录，包含30条幼儿园、13条小学、7条初中。记录数与独立机构数各自保留原口径。
- 27条记录取得OSM校园参照位置，合并同址学段后为24个地图入口。其余23条在可检索列表中显示“位置待核”，保留官方地址和来源。已定位记录按学段为幼儿园8条、小学12条、初中7条。
- 校园面采用面积几何中心，设施点保留OSM坐标。实际校门、步行路线和通学时长需要实地审计。海明学校与OSM旧名“体育东路小学（东校区）”的别名关联列为待进一步核验。
- 两条Nominatim地址检索结果指向“天河区儿童福利会幼儿园”，与体育西幼儿园、体育东路幼儿园的官方名称不符，已从展示点位排除。原始响应保留供复核。
- 街道界采用OSM参考边界。猎德与利民暂定为社区比较对象，当前展示其已知制度入口和供给历史。精确社区界、同口径学校密度、人口分母、固定半径及实际路线继续补证。
- 新昌与新蕾的金额属于正式批复标准。园校实际收费、下浮、餐费及减免抵扣仍需公示或缴费资料。页面逐项说明费用周期与政策条件。
- 家庭条件为构造情景。申请结果还涉及完整材料、时间、具体门牌、配套名单与审核。公开计划、实际报名和最终录取分别解释。
- 社会再生产用于提出机制解释，当前材料覆盖教育机会条件。代际学业和职业流动结果需要家庭与追踪资料。

## 轻量实现

页面采用原生HTML、CSS、JavaScript和Canvas，运行时第三方依赖为零。地图路网、水域、公园和参考边界为本地矢量数据，首次读取后即可拖动缩放。地理坐标统一为WGS84，经同一局部Web Mercator转换，避免混用地图服务的坐标偏移。

| 项目 | 控制方式 |
| --- | --- |
| 静态资源 | 全部约0.96MB，合计gzip约0.31MB，含地图、数据和本地字体 |
| 字体 | 仅标题字形子集约41KB，正文使用系统字体 |
| 绘制 | 路网预编译Path2D，交互时requestAnimationFrame合并绘制，闲置时停止刷新 |
| Canvas | 像素密度上限1.75，底图位图目标上限400万像素，约16MB像素存储 |
| 网络 | 地图瓦片请求为零，资料在浏览器内处理，点击原文才打开外部网站 |
| 大文件 | 约204MB的研究原件留在资料库，网站发布包包含实际使用的静态资源 |
| 动画 | 短时定位过渡，遵循减少动态效果偏好 |

资源测量为当前构建文件总量。实际网络传输取决于托管端压缩、缓存及协议开销，浏览器总内存另含页面、JS、图形与引擎开销。

## 验证记录

2026-11-12在本机Chromium完成12组交互回归，覆盖筛选与无结果、未定位详情、键盘标签、家庭积分条件、三种费用项目、大班减免、学校层级对口、同址学段、同学段比较限制、五个课堂场景、来源弹窗、URL恢复及地图缩放移动，未出现页面脚本错误。

390、768、1024、1920像素视口均检查了布局及水平溢出。另验证了真实鼠标点击升学连线、关联学段显现及跨学段导航。动画结束后的800毫秒观测窗口中，底图闲置重绘次数为0。验证使用本地预览资源，操作系统、浏览器和设备差异仍需结合展示设备复核。

地域显示增强后，补验了1440、390和768像素视口的完整边界定位、范围定义展开、来源窗口、覆盖层隐藏与恢复，以及学校界内与周边标记。完整范围定位按地图实际可用区域校验，桌面侧栏占用空间计入避让。

## 文件与更新

```text
dist/index.html              页面结构
dist/styles.css              视觉与响应式布局
dist/app.js                  筛选、详情、费用、关系、比较与来源

dist/assets/basemap.json     裁剪后的本地矢量地理数据
tools/prepare_data.py        从仓库CSV和OSM原件生成展示快照及点位CSV
server.mjs                  支持gzip和修改重载的本地预览服务器
.openai/hosting.json         已注册静态Site的身份与发布目录
```

资料维护应更新仓库`03_背景/教育专题/数据/`中的原表及来源登记，再在本目录运行。

```sh
python3 tools/prepare_data.py
npm run check
```

生成器读取本仓库相对路径，使用Python标准库。程序也会更新`03_背景/教育专题/地图/学校点位_WGS84.csv`。重新采集时需同步修改数据日期、位置映射与待核说明。独立网站发布副本携带已生成快照，数据再生成需回到完整研究仓库执行。

地理数据来源、查询范围、排除项与许可见[地图采集与点位说明](../../03_背景/教育专题/地图/交互地图数据说明.md)。OSM地理数据按ODbL提供，界面保留贡献者署名与许可链接。本地Noto Serif SC字体子集按SIL Open Font License提供，许可证位于`dist/assets/OFL.txt`。
