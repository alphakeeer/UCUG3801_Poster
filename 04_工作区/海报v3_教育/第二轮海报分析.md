# 第二轮海报：问题诊断与两版设计说明

2026-11-16。对象是第一轮 A–D 四版，以及本轮新做的 E、F 两版。

## 一、第一轮四版为什么抓不到重点

| 问题 | 表现 | 原因 |
| --- | --- | --- |
| 没有主角 | 4 个概念、5 个方法数字、2 个发现、5 步机制链、2 段分析、4 条局限、12 条参考，几乎同样大 | 按八部分清单逐项填满，没有决定哪一块最重要 |
| 看不出是猎德 | 标题「住得近，就能读得上吗？」放到任何城市都成立；四版里只有 B 用了一张现场照片 | 叙事从政策出发，田野考察只出现在方法栏的一行字里 |
| 标题有“AI 味” | 反问句、对仗短语（「一址四门」「四个透镜」）、大量「不等于」「需要分开看」式的对称表述 | 措辞追求概括和稳妥，缺少具体的人、物、地名 |
| 和课程脱节 | 页眉写了课程号，但概念与课程周次没有对应；课程第 7 周的主题正是「教育、迁移与户籍」 | 理论框架直接搬自交接文档，没有回到课程大纲 |
| 漏了一项硬要求 | 作业 PDF 第 7 页要求至少一张比较**两个社区**的视觉材料，四版都没有 | 发现二只比较同一地址下的四种身份 |

## 二、本轮的取舍

**1. 主线改成一句话：在猎德，学校就在附近，门槛在材料上。**
发现一说明“附近有没有学校”不是问题（房价高低与身边园校数无关）；发现二说明真正的分界是家庭能拿出哪种被认可的材料。

**2. 把猎德自己的历史放进论证。**
仓库的定向核验表里有两条官方确认的本地证据，第一轮没有用上：

- 拆迁安置户凭拆迁协议，可以在地段生之后优先排到地段学校（2026 细则附件 9，核验表 A11）；
- 猎德幼儿园 2026 年 135 个派位名额中，85 个先给配套小区的合格业主子女（派位计划第 52 行，核验表 A04）。

这样，“2007 年整体改造、2010 年回迁”就不再只是背景：改造留下的拆迁协议，今天成了一种入学凭证。这正是作业要求的社会学想象力，即把日常生活和历史、制度连起来。

**3. 补上两个社区对比。**
对比猎德花园（猎德村拆迁复建房）和南国花园（珠江新城商品住宅），两者直线相距约 870 米。对比项包括：参考价、500 米内园校数、地段小学与步行时间、幼儿园业主优先名额、入学特点。

**4. 标题换成具体的东西。**

- E：「房产证、户口本、拆迁协议」。三件实物就是本研究的分析对象，也直接对应“行政可读性”。
- F：「回迁户、业主与租户」。点名三类人，比较对象一眼可见。

两版都去掉了反问句和对仗口号。

**5. 概念减为 3 个，并标出课程周次。**
保留社会封闭（Weber，课程第 2 周）、户籍分层（Wu & Treiman，课程第 7 周）、行政可读性（Scott，延伸阅读）。“共同度量”只服务于一个计数指标，在海报上收益太小，所以删掉。

**6. 发现一直接使用定稿的 A3 地图。**
另加一处已核证据：最贵的颐德公馆与最便宜的誉城苑，部分门牌同属猎德实验学校小学部地段（细则附件 5 第 56 项）。房价差三倍，对应的却是同一所地段小学。

## 三、两版的区别

| | E 田野报告 | F 两个社区对照 |
| --- | --- | --- |
| 开头 | 整幅宗祠屋脊＋超高层照片，压上标题和研究问题 | 深蓝标题栏，紧接着就是两个社区的并排对比（含照片） |
| 叙事顺序 | 历史 → 发现一（地图）→ 发现二＋社区对比 → 分析 | 社区对比 → 背景 → 发现一（地图）→ 发现二（五类家庭卡片）→ 分析 |
| 气质 | 纪实、人文，像一篇田野报告 | 清楚、学术，最贴评分表 |
| 适合 | 展墙上吸引人走近；讲解从“这张照片”开始 | 老师按评分表逐项找；讲解从“这两个小区”开始 |

## 四、对照评分表

| 评分项 | E、F 中的位置 |
| --- | --- |
| 研究问题与聚焦（10） | 页眉一个问题，结论框一句话回答 |
| 概念与文献（15） | 3 个概念，每个都有定义和“在猎德”的应用；3 篇学术文献、4 份官方文件 |
| 证据质量与多样性（20） | A 实地观察（照片）、B 价格与环境审计（地图、路线）、C 政策文件；两个社区对比 |
| 不平等与社会流动分析（20） | 三段分析：谁能把“近”变成“能读”、改造历史变成凭证、对社会流动的含义 |
| 反身性、伦理与局限（10） | 4 条局限＋反身性；照片不含可识别人物与儿童 |
| 组织与视觉传达（10） | 地图和社区对比是两个视觉主角，其余内容退为小字 |

- E、F：分析栏小标题不再重复编号；F 的结论框改用编号 8，修正对勾显示成“V”的问题，局限和参考文献顺延为 9、10。
- 措辞：“步行几分钟就能互相到达”改为“在一两公里内同住”；后续问题缩短，避免最后一行只剩一个字。

## 七、统一标题（2026-11-16）

原来两版各用一个标题（「房产证、户口本、拆迁协议」「回迁户、业主与租户」），读者看不出海报的结论。现在两版统一为：

- 主标题：**猎德家门口的学校：入学看户籍和住房身份**
- 副标题：房价高低与身边学校多少关系不大；同一地段里，回迁户、业主和租户凭不同材料入学

写法是“地点与对象：结论”。前半句交代在哪里、研究什么，后半句直接给出答案，副标题再把两项发现各压成一句。E 在标题上方保留「房产证 · 户口本 · 拆迁协议 · 租赁备案」一行小字，作为视觉引子。

## 八、方案 E 视觉打磨（2026-11-16）

### 参考了什么

- **#betterposter 的讨论**（MIT Communication Lab）：做一个三秒测试，扫一眼能否抓住结论；版面应留出足够空白 [a]。
- **研究海报设计指南**（Wayne State、Purdue OWL、UNM、Argonne）：用层级给元素排序；结果应占最大面积；按“接近原则”分组 [b][c][d][e]。
- **中文海报排版经验**：文字分三层，次要信息字号约为标题一半；字体不超过两种，颜色不超过三种；颜色用来分块，要节制 [f][g]。
- **Butterick《Practical Typography》**：行距取字号的 120–145% [h]。
- **W3C 中文排版需求（clreq）的讨论稿**：书籍正文横排每行多在 17–40 字之间，48 字为上限 [i]。
- **竖版阅读路径**：区块自上而下堆叠，关键信息放在路径的起点和终点 [j]。

### 诊断与改动

| 问题 | 改动 |
| --- | --- |
| 正文字号在 11–13.5px 之间来回跳，看起来零碎 | 定一套字号：标题 64 · 区块标题 24 · 小标题 15 · 正文 13 · 注释 11.5 · 参考 9.4 |
| 金色同时用作标题强调和地图上的“低于 10 万”，语义相撞 | 颜色各管一件事：珊瑚、砖红表示“门槛与高价”，金色只表示低价，青绿只表示学校。标题强调改为珊瑚色 |
| 头图顶部既有课程信息，又有一行材料清单的小字，太挤 | 删掉材料清单；研究问题里的“房价、户籍、住房身份”加粗并加下划线，回应标题 |
| 分析区只有第一栏带“06”编号，三栏不对称；小标题折行，正文起点参差 | 改成整行一个标题“06 社会学分析”；三栏用 A／B／C 加一条粗线起头，小标题缩短成一行 |
| 地图标注约 10px，屏幕上难读 | 标注文字单独放大 12% |
| 社区对比表左上角是空白格 | 补上“两个社区”标签 |
| 栏间距有 20、24、28 三种 | 统一为 24px |
| 第 05 部分标签 | 改为「发现二 · 不同住房身份与入学资格」 |

### 英文版的处理

- 标题：**Schools Next Door in Liede: Hukou and Housing Status Decide Entry**，与中文标题同构（“地点与对象：结论”）。
- 楼盘名使用交接数据中的英文名（`name_en`）；学校名按官方名称意译（如 Liede Exp. Primary）。
- 小学图标里的“小”在英文版改为“P”；比例尺用 250 m，以便与图例放在同一行。
- 参考文献中的中文官方文件标注 [in Chinese]，书目信息不变。
- 英文正文更长，所以英文版字号整体约小 0.6–1px；各栏宽度单独调过，保证仍在画布内。
