# 当前研究方向　教育设施分布与教育机会不平等

确定日期为2026-11-09。小组选择围绕猎德居民教育展开，重点考察小学、幼儿园等设施的分布差异、形成原因及其对不同家庭教育机会的影响。研究以社会不平等、阶层与社会流动为分析主线。

## 一　暂定标题与研究问题

### 《住得近，就能读得上吗？》

猎德地区教育设施分布与家庭教育机会差异。

**分析性研究问题**

> 猎德地区小学和幼儿园的空间分布，如何与招生资格、收费和家庭住房条件相互作用，影响不同家庭获得教育资源的机会？

组织建议为小学作为主体、幼儿园作为补充，两个阶段独立分析。具体学校清单和两个比较社区待依据官方资料、实际路线及教学要求确认。

[交通可达性调研（两轮综合）](交通可达性/README.md)提供三处住宅样本的地图路线、招生地段对照及海报图表，可用于选择现场复测路线。

### 三个子问题

1. 分布差异。两个社区及其附近的同阶段学校在类型、数量和实际步行距离上有什么差异？
2. 形成原因。住宅开发、人口需求、历史配套及招生安排怎样解释这些差异？
3. 不平等影响。预算、住房、申请条件和家庭支持不同的家庭，可行学校选择及通学、经济负担是否不同？

## 二　解释对象与机制

研究关心不同资源及制度条件如何转化为教育机会。先记录附近供给，再核验家庭能申请、负担和实际使用哪些教育资源。

**家庭居住与经济条件 → 附近学校及申请条件 → 实际可行学校选择 → 通学、费用与学习机会差异**

| 层次 | 要核对的问题 | 证据 |
| --- | --- | --- |
| 空间供给 | 有哪些学校，属于什么阶段与类型，实际路线多远 | 官方名录、学校地址、地图与现场核验 |
| 制度入口 | 招生范围、资格、申请类别及流程是什么 | 当年招生文件与学校简章 |
| 经济与支持条件 | 必要费用、接送及申请信息需要什么家庭投入 | 公开费用、实际路线、可选匿名成年家长交流 |
| 实际机会 | 家庭能申请及持续使用哪些选择，承担什么成本 | 与条件相对应的申请、预算及使用记录 |
| 长期结果 | 学习、升学和职业流动有什么变化 | 需纵向资料，列为后续研究 |

比较家庭条件时依据实际规则或自愿自述，住房类型、租住与自住、户籍等维度分别核验。家庭收入、资格与教育质量均不能由建筑外观或地图评分推定。

## 三　社会学概念与证据解释

| 概念 | 定义及本题应用 | 怎样用证据检验 |
| --- | --- | --- |
| 空间不平等 | 居住位置与资源分布相交，可能使获得教育资源的距离和成本不同 | 两社区同阶段学校分布、实际路线、过街及其他障碍，结合需求和容量解释 |
| 制度性分层 | 招生范围、申请类别、资格和程序可能使不同家庭进入不同申请路径 | 按同年正式文件比较资格、地段和申请流程，保留满足条件及替代渠道的案例 |
| 社会再生产 | 家庭资源可通过住房、信息、费用及照护支持转化为下一代的机会条件 | 比较必要投入与家庭可用支持，研究公共供给怎样增加或限制可行选择 |

社会再生产用于连接阶层与教育机会。预算和接送支持较充分的家庭可能具有更多替代选择，资源较少的家庭可能更依赖附近公共供给。这是待检验机制，实际差异需资料支持。

公共教育供给也可能缩小家庭资源差异，应记录免费或低负担渠道、支持措施和与初始假设相反的结果。短期课程研究优先解释机会条件及近期成本，长期流动结果另需追踪。

## 四　可能原因与替代解释

| 待检验原因 | 要找的资料 | 解释边界 |
| --- | --- | --- |
| 历史与规划配套 | 建设及开办年份、住宅开发与教育规划 | 当前地图无法独立还原形成过程 |
| 适龄人口与需求 | 同年同边界适龄儿童、招生计划及学位 | 数量少也可能与需求少或校规模大有关 |
| 土地与开发方式 | 学校用地、项目配建及办学主体资料 | 不从土地价值直接推定学校质量 |
| 招生制度 | 当年范围、资格、类别与流程 | 幼儿园与小学分别核对，不同申请路径保留 |
| 家庭资源与支持 | 预算、信息来源、接送及申请经验 | 自愿匿名资料，便利样本限定解释范围 |

教育设施分布与家庭选择可能相互关联。学校选择可能影响居住地点，家庭也可能依据预算选择住房，因此地理关联的因果方向需要谨慎判断。

## 五　优先分析的影响

- 可行学校选择的数量及类型，区分附近设施和符合条件的申请选择。
- 通学路线、时间和接送负担，实际路线与直线距离分别记录。
- 必要费用与附加支出，幼儿园、义务教育及其他收费口径分别核验。
- 获取招生信息、完成申请和安排替代服务所需的家庭投入。
- 如有真实记录，分析家庭怎样取舍，保留公共支持减轻负担的案例。

学业成绩、升学和职业流动列为更长期的研究问题。现阶段缺少相应纵向数据，结论聚焦教育机会及负担。

## 六　范围与两社区比较

先划定猎德地区的研究边界，明确街道、社区、住宅片区与学校招生范围的区别。两个社区由实际路线和教学要求确认。

在两地采用相同指标。小学和幼儿园分组，公办、民办及幼儿园普惠属性按官方资料标注。若使用统一距离或步行时间作为检索范围，应说明它属于研究操作口径，正式招生范围依据当年规则。

比较至少包含同阶段设施分布，以及距离、类型、申请入口或必要费用中的一项。学校数量、人均或需求指标只有在统计期和边界一致时组合。

## 七　最小证据计划

| 证据类型 | 采集内容 | 应保存的元信息 |
| --- | --- | --- |
| A系统观察 | 校门及道路、过街条件、公开公告、可到达入口 | 时间、地点、记录者、观察位置、照片编号及进入限制 |
| B环境或费用审计 | 同口径路线、公开收费、资格和申请流程的比较 | 起终点、路线方式、费用单位与周期、公告日期、来源 |
| C背景研究 | 官方学校名录、招生细则、园校简章、规划及学术研究 | 原链接、发布日期、统计期、页码及适用范围 |
| D可选交流 | 成年家长的信息、预算、申请及接送经验 | 知情同意、匿名编号、时间和转述范围 |

课程要求至少三类证据，可采用A+B+C。D自愿开展。地图截图属于C类材料，现场观察需另存记录。拍摄聚焦建筑和公告，按课程要求保护儿童及个人信息。

### 建议数据字段

| 字段组 | 字段 |
| --- | --- |
| 学校识别 | 编号、正式名称、办学阶段、地址、来源、核验日期 |
| 办学属性 | 公办或民办、幼儿园普惠属性、实际办学状态 |
| 空间与容量 | 所属研究单元、路线起点与终点、实际步行距离或时间、障碍、招生计划或学位 |
| 制度入口 | 招生范围、适用家庭类别、资格、材料与申请流程 |
| 费用与支持 | 收费项目、金额、单位、周期、附加支出及支持措施 |
| 记录限制 | 缺失、口径差异、版本、无法确认事项及替代解释 |

以上为待采集字段，正式学校名单和比较数据尚待建立。

## 十　研究局限及其影响

1. 学校数量与学位容量不同。缺少招生规模和适龄人口时，无法判断供需是否充足。
2. 地图可能遗漏或分类错误。样本范围和办学阶段若不核对，会扭曲设施分布。
3. 地理距离与申请资格分别作用。只测距离可能高估家庭可行选择。
4. 家庭背景资料有限。缺少预算、申请和接送经验时，结论限定为机会条件及潜在门槛。
5. 横截面资料难以解释长期结果。当前分布和制度无法独立识别对成绩、升学或职业的因果效应。
6. 学校及社区需求不同。规模、办学类型、年龄结构和发展阶段应进入替代解释。
7. 因果方向可能交错。择校影响居住与居住约束影响择校可能同时存在。
8. 观察和交流范围有限。单时段、公开区域和便利样本可能遗漏其他家庭需求，按实际范围报告。
