## 使用方式

将每个后续写作论断对应到编号。F表示文件直接支持的事实，I表示机制解释，Q表示待核验命题。A为本组系统观察，B为本组价格或环境审计，C为外部背景研究，D为自愿知情的简短交流。

当前已整理的来源属于C类。以下A、B、D任务为采集方案，空白记录保持待填。引用政策时检查[政策矩阵](../../03_背景/数据/09_政策适用与版本矩阵.csv)，引用数字时检查[数据字典](../../03_背景/数据/数据字典与计算说明.md)。

## 可直接执行的最小采集方案

### 共同部分

建议先完成两个社区、两个窗口的配对记录。每一窗口两人同行，一人记事实，一人核对时间和位置。同一地点工作日、周末各至少观察一次，每次约30分钟。若只能完成一次，在局限中写明。

记录具体日期和天气、观察起止、公开位置、设施名称、入口及公告。计数单位提前统一，可选“进入事件”或“在场人数”，两者分开记录。重复进出无法识别时说明，禁止据外貌推断阶层、户籍或原村民身份。

现有通用记录入口为[现场记录与说明](../../02_现场/现场记录与说明.md)，以下字段专门服务本轮两方向。

### B1类住房与租赁审计

两社区各选至少3条可比公开挂牌信息，选择条件一致后再采集。该数量为小组执行建议，样本规模有限。

| 字段 | 规则 |
| --- | --- |
| 记录ID、日期、网址或公告照片 | 保留挂牌依据，去除个人联系方式 |
| 社区、街段、物业类型 | 历史村、复建区与商品住宅分别记录 |
| 整租/合租、面积、房间、楼层、装修 | 不可比字段注明缺失，避免凑对 |
| 月报价、物业、押付、中介及其他费用 | 价格与费用分列，挂牌与成交分开 |
| 交通与环境 | 同口径路线、过街、沿街用途和公开设施 |
| 重复挂牌与复核 | 去重规则和复核人 |

计算每平方米月报价时，只使用面积和报价口径完整、整租类型一致的条目，保留原值。样本少时使用逐条比较，结论限定为所采挂牌。

### D类简短自愿交流

开场可说，我们是课程小组，正在了解社区生活与公共服务，想用几分钟记录不涉及姓名的情况。可跳过问题或随时结束，是否愿意参与。记录同意方式和时间，录音与可识别照片另行征得明确同意。

**住房方向可问**

1. 您大约什么时候开始在这一带居住或经营，是否愿意说明是租住、自住还是其他安排？
2. 您感受到哪些居住成本或生活便利变化，哪一项最重要？
3. 获取工作、学习或社区信息时，通常使用哪些渠道？
4. 如果了解改造历史，哪些变化是亲历，哪些来自他人转述？
5. 有哪些经历与我们的问题假设不一致，或容易被外部观察者忽略？

**服务方向可问**

1. 您是否知道或使用这项服务，最近一次是什么时候？不使用也可以记录。
2. 一般哪几天、哪些时段方便到访，是否受工作、照护或交通影响？
3. 有没有遇到项目不合适、预约、名额、收费或信息方面的困难？
4. 是否有其他地点或线上服务满足需要？
5. 如果使用过，是否获得信息、技能、结识他人或其他帮助？可否举不涉及个人身份的例子？

建议接触多个作息和使用状态的人，便利抽样数量由时间与同意情况决定。用描述性案例呈现，样本不足时不计算代表全社区的百分比。未成年人采用课程与机构要求的监护及同意程序，短期小组可优先访问自愿成年受访者。

## 收到新材料后的处理流程

1. 保存原件，登记日期、原URL或提供人、授权和适用范围。个人记录存匿名版，敏感原件单独控制访问。
2. 提取正文并标注原页码，若是扫描或OCR注明转写方法。
3. 将数字写入表格，同时填单位、时期、空间或样本范围、口径及局限。
4. 与现有资料冲突时保留两者，先查版本、统计边界、对象和阶段。
5. 更新对应论断为F、I或Q，删改超出证据的推论。
6. 指定另一成员复核关键数字及引语同意，再进入后续写作与制作。

## 最终研究检查

公开资料已覆盖两方向的问题、文献、数据与制度背景。小组需把实际A、B类记录和可选D类交流补入，完成两社区可比性核验，再判断哪些结论可进入最终成果。若某项证据始终无法取得，明确限定该论断的范围，并将局限对解释的影响写入正文。
