# 地图交互网页展示设计

设计日期为2026-11-12，资料版本截至2026-11-10。当前方案采用地图贯穿全程的交互网页，学校详情、申请条件、费用和比较随地图选择联动。

## 研究问题与展示目标

沿用《住得近，就能读得上吗？》。观众通过位置、家庭条件和学校关系的交互，理解猎德教育机会如何受到公共供给、住房、户籍、学位分配及费用支持的影响。

核心概念为空间不平等、制度性分层和社会再生产。公共新建园、积分学位及减免政策同时进入解释。

## 页面构成

桌面端优先适配课堂投影与笔记本。地图占据主要视野，右侧详情仅在选中对象后展开。手机端通过底部抽屉查看筛选和详情。

| 位置 | 内容 | 行为 |
| --- | --- | --- |
| 顶部窄栏 | 标题、学校检索、资料日期、展示模式 | 检索定位学校，切换模式时保留地图位置及已选对象 |
| 左上浮动栏 | 学段、办学主体、研究范围等图层控制 | 地图点位和当前结果数同步更新，支持收起 |
| 地图主体 | 道路、河流、学校、研究边界、当前对象 | 拖动、缩放、点击学校、选择比较对象 |
| 右侧抽屉 | 学校或社区详情 | 查看概况、入学、费用、来源及相关学校 |
| 底部分析面板 | 与当前选择相关的计划、费用、关系或比较 | 点击图中对象联动地图，面板支持展开和收起 |
| 地图角落 | 图例、比例尺、回到研究区、来源 | 根据当前模式更新图例，底图与研究图层各有出处 |

打开页面时展示猎德街道及相邻区域，模式为“分布”。首屏保留学段开关、边界和简短图例。学校检索、模式、详情和图表共同使用同一选择状态。

## 五种展示模式

### 分布

地图显示学校及园区。学段支持幼儿园、小学、初中切换，举办主体通过稳定的颜色和文字图例表达。同址多学段通过一个位置入口展开，详细记录保留学段属性。

点击学校后，地图突出该点，右侧显示名称、地址、办学阶段、举办主体、计划摘要、价格依据及来源。点击详情中的相关学校，可将地图定位到对应对象。

缩放和筛选影响当前结果数。数字旁写明统计单位，如园区、校区或校区学段。相邻片区候选在位置核验后进入地图，未取得可靠坐标的记录保留在可检索名单中并显示定位状态。

### 入学

左侧展开条件面板，按研究文件涉及的维度询问学段、儿童户籍、住房或租住情况、相关居住证明和时间条件。界面提供少量构造情景，便于课堂讲解，情景名称写明条件。

每次选择后，地图和右侧说明显示有文件依据的申请渠道、需要补充的证明、适用时间及逐校待核条件。学校点位上的标记对应优先登记、社会派位、统筹、积分或其他文件路径。具体规则展开后附来源定位。

未取得逐园小区名单、校方细则等关键材料时，对应结果显示待核原因。一般规则与学校具体规则都进入说明，结果用申请路径和材料要求表达。

底部可展示当前学校的名额结构。例如猎德幼儿园公布社会电脑派位135人，其中业主子女85、剩余随机50。图中分组及人数均使用原表口径。

### 费用

地图点位显示所选学段、所选费用项目的金额与单位。切换学校时，右侧显示批复标准、执行期、新老生条件、实际公示状态及相关补贴。选择多所学校后，底部出现同学段、同项目、同周期的比较图。

首版已有新蕾小学8000元、新昌小学8700元、新昌初中10600元每人每学期的正式批复。公办义务教育学费免收、大班保教费减免、民办积分补贴等以适用条件呈现。

实际公示、餐费、托管、交通和减免抵扣仍缺失时，费用面板保留待核字段。图中批复金额附证据类型，家庭总负担需在对应资料补齐后计算。

### 升学

选择一所小学后，在地图中显示文件支持的对口初中，并以连线表达升学关系。选择初中时，可查看其对口小学或文件列明的派位对象。

连线采用箭头表达方向，实线和虚线配合文字表达对口与自主报名派位等关系。点击连线显示对应年级、资格、计划类别、资料年份及原文。

天河中学的20班为学校层级计划，校区分流资料尚缺，因此关系详情按学校层级引用该数字。同址小学初中、同校多校区的关系以现有证据层级呈现。

底部面板提供当前学校的关系概览。关系图节点与地图学校互相定位，图表中的当前选择与右侧详情一致。

### 比较

观众可以选择两所同学段学校，或者选择两个有明确范围的社区。底部出现并排比较面板，地图同时突出所选对象。

学校比较优先显示办学主体、招生路径、公布名额、费用依据及待核项。社区比较使用相同统计范围、学段、单位和观察口径，并显示边界及资料年份。

猎德社区与利民社区暂定为社区比较对象。其正式课堂适用性、当前边界和同口径路线仍需核验。现阶段可比较已核制度和供给历史，空间数量与时间负担待点位及审计资料补齐后呈现。

比较数量、距离和费用均显示来源及缺失状态。独立机构、园区、校区、学段和总体或专项计划的包含关系在计数前核对。

## 补充模块

### 公共供给时间线

在选中华文幼儿园或利民社区时，底部面板提供2022居民诉求及项目批复、2023开工、2024封顶、2025开园、2026招生名录的时间线。点击事件定位相关位置并显示来源。

时间线中的总容量、当年小班招生计划和报道经历各自保留原始口径。若后续资料补齐，可加入其他学校开办和政策变化事件。

### 研究解释

右侧或底部提供与当前选择相关的简短解释。选中业主与随机名额时提示制度性分层，查看建园和路线时提示空间不平等，查看住房条件与教育路径时提示社会再生产。

每条解释联系当前对象、具体事实、机制和证据局限。观众可展开查看反例，如公共供给新增、积分渠道和费用减免怎样扩大选择。

### 来源与数据状态

来源入口显示文件标题、发布及适用日期、机构、页码或原行、摘录和本地原件。来源目录可通过学校或具体论断进入。页面显著位置写明数据截至2026-11-10。

### 展示模式

为课堂提供五个可点击研究场景。

1. 观察猎德及周边三学段分布。
2. 选择猎德幼儿园并打开名额分配。
3. 调整家庭条件并查看文件中的申请路径。
4. 选中小学并查看初中关系。
5. 打开猎德与利民的比较及公共供给时间线。

切换场景时恢复对应地图视野、学校选择和面板。演讲者可随时拖动地图或点击其他对象，之后回到场景。场景只保存展示状态，数字和规则继续引用同一数据源。

## 交互验收

| 操作 | 地图变化 | 面板变化 |
| --- | --- | --- |
| 检索并选中学校 | 定位并突出该学校 | 打开相应详情 |
| 切换学段或主体 | 可见点位和数量更新 | 图例及有效比较对象更新 |
| 点击图表中的学校 | 对应点位突出 | 当前学校详情同步 |
| 选择家庭条件 | 显示对应文件路径的标记 | 条件、材料、依据和待核原因同步 |
| 点击升学连线 | 突出相关小学与初中 | 展示关系和适用条件 |
| 加入两个比较对象 | 同时突出两个对象 | 展示同口径比较 |
| 切换研究场景 | 恢复相应视野及选择 | 恢复所需说明与图表 |
| 打开来源 | 保留当前地理参照 | 显示对应原文定位 |

关闭详情时保留筛选和地图视野。切换学段导致已选对象失效时，界面明确说明并提示可选对象。键盘可访问模式按钮、筛选、学校列表、详情及来源，颜色同时配合文字或形状。

## 视觉方向

采用暖白或浅灰底图，降低道路与非研究地名的视觉权重，保留珠江、关键道路与研究边界。深蓝为主要文字与选择色，青绿和赭金用于必要的数据类别。中文标题使用衬线体，操作和图表使用清晰的无衬线体。

地图默认占主要面积，抽屉和分析面板支持收起。最多同时展开一组主要详情与一个底部分析面板。投影场景重点检查学校名、人数、单位和图例的可读性。

动画用于地图定位、面板开合和关系高亮，尊重减少动态效果设置。原始地图保留来源、版本和审图信息，研究绘制的边界记录依据与误差。

## 数据与实现顺序

| 顺序 | 工作 | 完成条件 |
| --- | --- | --- |
| 1 | 校区身份与地理定位 | 首版点位有可靠坐标、来源、定位精度及同址关联 |
| 2 | 地图、筛选、检索与详情 | 学校可查找，地图和详情双向联动，状态可恢复 |
| 3 | 招生、费用和升学模块 | 关键数字附对象、单位、年度及出处，条件说明可追溯 |
| 4 | 比较、时间线和展示场景 | 对象与口径一致，场景可进入、自由探索并返回 |
| 5 | 移动与投影验证 | 面板可收起，主信息清晰，键盘和触屏操作可用 |

当前有30条幼儿园和20条小学初中校区学段候选。坐标、精确社区边界、1/2公里筛选、实际路线和逐园实收费仍待补齐。地图上已有定位的对象和说明必须保留所采用的证据年份及精度。
