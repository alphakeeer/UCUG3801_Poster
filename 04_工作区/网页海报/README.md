# 猎德公共文化服务研究海报

中文单页网页海报，配研究详解、可交互情景分析、单页 PDF 和高清 PNG。静态站点，正文、图表与字体资源均随项目保存。

## 启动与导出

在本目录运行 `npm start`，打开终端显示的本地网址。静态文件位于 `dist/`。

重新导出时，先运行 `npm install` 与 `npx playwright install chromium`，再运行 `npm run export`。导出文件保存到 `dist/assets/` 和仓库的 `05_提交/poster_final/`。

## 内容与数据

- `dist/index.html` 保存正文、研究状态及来源链接。
- `dist/app.js` 保存三项设施的公布时段，图表、时长和情景分析由同一组时段计算。
- `dist/styles.css` 保存海报、移动端与打印样式。
- `dist/assets/` 保存本地字体、档案影像及导出文件。

数字按官方目录公布的常规时段计算。工作日白天与晚间的日程交叠属于明确标注的假设情景。

## 当前研究状态

本版为公开资料研究版，已完成案头时段编码、同类设施对照和社会学分析框架。组员姓名、实际实地日期、系统观察和环境核验待补，猎德与利民的样本范围需与课程路线核对。9:16 比例依据 Canvas 本地快照，最终版式待教学团队确认。

## 素材来源

- 城市影像来自广州市档案馆《历史与现代融合的典范——老城市新活力：广州猎德村的变迁》，画面标注年份为 2020，图文署名为市国家档案馆声像档案部。原始图片与网页出处在海报及网页中标注。
- 字体为 Google Fonts 提供的 Noto Serif SC 与 Noto Sans SC，按本页字符制作字体子集，使用 SIL Open Font License。许可文本保存在 `dist/assets/OFL-Noto.txt`。
- 原始研究来源及其使用范围详见 `../../03_背景/网上资料研究包.md`。
