# 中文交接包的维护说明

普通组员直接阅读[仓库首页](../../README.md)、[逐项资料目录](../../交接资料/资料目录.md)或[中文工作簿](../../交接资料/研究资料与综合数据.xlsx)。本页仅供更新资料的维护者。

## 当前整合关系

交接版把新增图包的空间资料与上一轮独立审查后的政策、费用和路线接在同一工作簿中，不改写专题原件，也没有重跑原包的地图绘制程序。

|内容|现用输入|处理方式|
|---|---|---|
|住宅、园校、位置、价格及直线邻近|`04_工作区/研究分析/图表与数据补充/ucug3801-housing-education-spatial/data/`|22住宅、43园校、66观察；编号与旧18住宅／43园校逐项核对；保留价格更正前指标|
|招生规则、计划、渠道、费用、路线、缺口、来源|`06_数据整合/outputs/data/`|沿用审查后的基线；新增住宅不补造路线或个人资格|
|南国花园四类家庭情境|`ucug3801-composite-figures/same-address-admission-scenarios.csv`|译为中文可读字段；租户去向和路线保留未知|
|现用图|新图包与上一轮双系列路线图|逐字节复制为中文文件名，记录替换／互补关系；不重绘原图|
|资料清单|已纳入Git的研究材料及明确生成的现用入口|分领域列出原件、数据、图、文献、现场、历史材料；不读入或发布他人未提交草稿|

未把空间资料写回旧标准化CSV；它们继续作为已审历史基线保存。因此更新空间分析应使用中文交接包及其登记的新图包输入，不能仍把旧 `residences.csv` 当成22项目的当前基表。旧管线与新交接导出有不同的输出目录，避免互相覆盖。

## 重新生成

在仓库根目录运行，使用已有虚拟环境即可：

```bash
uv pip install --python 06_数据整合/.venv/bin/python -r 06_数据整合/maintenance/requirements-handoff.txt
06_数据整合/.venv/bin/python 06_数据整合/maintenance/build_handoff.py
```

入口只写 `交接资料/研究资料与综合数据.xlsx`、`交接资料/资料目录.md`、`交接资料/交接版本与核对记录.json` 和明确列出的 `交接资料/图表/` 文件，不修改其他组员报告、Poster或历史输入。仓库首页为人工整理的中文图文说明，需要有实质数据变化时另行同步。

工作簿固定表名、表头、数值类型与空白，支持筛选；原编号放在末列供追溯。导出后读取工作簿核验对象数、学段、零与缺失、机构去重、异常路线、原件图字节及文件链接；失败直接报错。相同输入固定工作簿内压缩时间，支持逐字节复现。

## 更新时要同步什么

1. 新材料先原样归档并登记来源，明确对象、年份、指标和核验强度。
2. 保留已有住宅／园校编号；机构、校区、项目POI与路线门点不能互相替代。
3. 冲突按原证据并列，不能只挑一个值。新增家庭或路线证据必须给出明确对象和出处。
4. 导出工作簿并检查首页数字、图注、现用图和版本关系。原图包内脚本以旧提交为基准，不直接在成员工作目录运行。
5. 仅提交本轮交接文件及相关维护文件；其他组员的未提交工作保持原样。

历史基线的自动测试和 `run.py validate` 仍可单独运行；它们检验旧规范表的可复现性，不代表已经验证新图包所有外部事实或实际校门。
